### JOB PURPOSE – ( Flutter - Development )

### PRINCIPAL ACCOUNTABILITIES
- Design and maintain robust, modular, and scalable applications for iOS, Android, and Web browsers, ensuring a highly decoupled code architecture (e.g., Clean Architecture, BLoC/Riverpod) that allows independent feature development by multiple squads.
- Architect responsive, multi-browser web portals (internal Dashboards, Loan Origination Systems) and mobile apps, carefully optimizing the Flutter web rendering engine (CanvasKit vs. HTML) to guarantee pixel-perfect UI and flawless usability across Google Chrome, Safari, and Microsoft Edge.
- Lead the seamless integration of critical financial APIs and SDKs, including Digital KYC/Onboarding tools (OCR, Liveness checks), Credit Bureaus (CIBIL/Experian), core banking systems, and complex Payment Gateways/UPI intent flows.
- Own the implementation of strict mobile and web security protocols, including SSL/TLS certificate pinning, mTLS, biometric authentication, hardware-backed secure storage on mobile, and HTTP-only cookie management to prevent XSS/CSRF on browsers.
- Establish and enforce strict coding standards, code review processes, and CI/CD pipelines to ensure rapid, secure deployment cycles across the App Store, Google Play, and web servers.
- Profile, diagnose, and optimize application performance (reducing app cold start times, fixing cross-browser memory leaks, and managing bundle sizes) while mentoring mid-level and junior developers in advanced Flutter best practices.

### SKILLS AND KNOWLEDGE
- **Clean Architecture & DDD (Domain-Driven Design):** Strict separation of concerns into Presentation, Domain (Business Logic/Entities), and Data layers. This ensures that changing a payment gateway API doesn't break the UI.
- **Modularization:** For large banking apps (containing modules like Loans, Credit Cards, Insurance, and Rewards), know how to break the app into independent, testable feature packages/modules rather than keeping it a monolith.
- **State Management Mastery:** Deep production experience with BLoC (Business Logic Component) or Riverpod. Understand when not to rebuild widgets and how to optimize streams to prevent battery drain.
- **Deep Linking:** Flawless execution of Android App Links and iOS Universal Links for contextual payment journeys or loan application follow-ups, preventing link hijacking.
- **Background Sync Engines:** Building robust sync pipelines using background workers (workmanager). If a loan agent uploads a PDF document in a dead zone, the app must safely queue the payload locally in SQLite/Hive and auto-retry syncing once connectivity returns.
- **Local Data & Caching:** Experience designing robust local caching layers using Hive, Isar, or SQLite.
- **Modularization:** Proven track record of breaking down monolithic codebases into highly reusable, independent Dart packages and local plugins.
- **Language Proficiency:** Deep mastery of Dart (including asynchronous programming, isolates, and sound null safety) along with strong proficiency in Swift/Objective-C or Kotlin/Java.
- **Mentorship & Governance:** Lead code reviews, author technical design documents (RFCs), and establish coding standards to elevate the engineering team's capabilities.
- **Security & Compliance:** Implement enterprise-grade security protocols, including secure storage, SSL pinning, OAuth/OIDC authentication, and data encryption at rest and in transit.
- **Web Optimization:** Address web-specific challenges including initial load times, bundle splitting, lazy loading, and rendering backend selection (HTML/CanvasKit vs. Skwasm).
- **Educational Qualifications:** IT Graduate.
- **Functional Skills:** Dart & Flutter Framework Mastery, State Management & Architecture, Mobile & Web Security, Database & Offline Sync, API & Web Integration, Native Platform Development, DevOps, CI/CD, & Testing.
