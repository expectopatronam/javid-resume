WritingJob Description: Software Engineer – Generative AI & LLMJob Summary

We are seeking a talented and innovative Software Engineer specializing in Generative AI and Large Language Models (LLMs) to design, develop, and integrate intelligent AI-powered applications. The ideal candidate should have strong Python programming skills, practical experience with Generative AI technologies, and the ability to transform business requirements into reliable, scalable, and efficient AI solutions.

    Design, develop, and deploy AI-powered applications using Generative AI technologies and Large Language Models.
    Integrate LLM APIs and open-source models into software applications to enable intelligent automation and natural language interactions.
    Develop and optimize Retrieval-Augmented Generation (RAG) pipelines for context-aware responses and document-based information retrieval.
    Work with vector databases to implement embeddings, semantic search, and efficient retrieval mechanisms.
    Apply prompt engineering techniques to improve response accuracy, consistency, and relevance.
    Develop scalable backend services and REST APIs using Python and FastAPI.

    Collaborate with engineering and product teams to design and deliver production-ready AI features.
    Write clean, reusable, maintainable code and follow software engineering best practices.
    Use Git for version control and participate in code reviews, testing, debugging, and continuous improvement.
