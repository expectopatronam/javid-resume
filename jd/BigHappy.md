## About Big Happy
Big Happy is a high-growth company combining DOOH + mobile-focused creative with publisher media to create interactive 2D and 3D digital experiences across publisher web pages that wow modern consumers and drive brand outcomes for Fortune 500 brand partners.

## Key Responsibilities
- Design and develop dynamic, responsive, and interactive web applications using HTML5, CSS3, and JavaScript (ES6+).
- Collaborate with UI/UX designers to transform wireframes and designs into functional, visually appealing user interfaces.
- Write clean, maintainable, and efficient code adhering to best practices in performance optimization and accessibility.
- Build reusable components and front-end libraries to support scalability and consistency.
- Integrate front-end interfaces with backend services and RESTful APIs for seamless data communication.
- Optimize web applications for performance, accessibility, and mobile responsiveness.
- Participate in code reviews and CI/CD workflows using Git.

## Requirements
- 2–4 years of proven experience as a Front-end Developer.
- Strong knowledge of HTML5, CSS3, and Vanilla JavaScript (ES6+).
- Experience building responsive, mobile-first web applications.
- Strong understanding of web performance optimization and security.
- Proficiency in integrating RESTful APIs and handling JSON data for dynamic interfaces.
- Experience with front-end build tools such as Webpack.
- Familiarity with version control systems like Git.
- Cross-browser compatibility knowledge and modern responsive solutions.
- Proficiency with TypeScript and modern JavaScript frameworks.
- Strong English communication skills and ability to work in US time zones (EST/PST).

## Preferred Skills (Bonus)
- Experience with state management (Redux).
- Proficiency in graph/canvas libraries (D3.js, Canvas.js, HTML5 Canvas) for data visualization.
