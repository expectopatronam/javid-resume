Job Description

We are looking for a highly skilled Senior Flutter Developer with 5–10 years of software development experience, including 4+ years of hands-on Flutter development, to build high-performance, scalable, and visually appealing cross-platform mobile applications. The ideal candidate should have strong expertise in Flutter, Dart, mobile architecture, API integration, state management, and application performance optimization.

Key Responsibilities

    Design, develop, test, and maintain cross-platform mobile applications using Flutter and Dart.
    Build reusable, scalable, and maintainable code following clean architecture principles.
    Collaborate with Product Managers, UI/UX Designers, QA Engineers, and Backend Developers to deliver high-quality applications.
    Integrate RESTful APIs and third-party SDKs.
    Implement responsive UI components with pixel-perfect designs.
    Optimize application performance, memory usage, and startup time.
    Write unit tests, widget tests, and integration tests.
    Troubleshoot and resolve application bugs and production issues.
    Participate in code reviews and mentor junior Flutter developers.
    Ensure application security and follow mobile development best practices.
    Publish and maintain applications on Google Play Store and Apple App Store.
    Stay updated with the latest Flutter releases and mobile development trends.
